## 已確認事實

- GitHub changelog（2026-11-17）：MAI Code 2 為通用模型，用於深度除錯、多檔實作、重構與整個 repo 推理；MAI Code 2 Flash 為輕量低成本模型，用於程式碼說明、局部修改、例行修復。
- MAI Code 2：Pro、Pro+、Max、Business、Enterprise；MAI Code 2 Flash：另含 Free 與 Student；年繳方案的合格訂閱者亦可使用。
- 可在 VS Code、Visual Studio、Copilot CLI、cloud agent、Copilot app、github.com、GitHub Mobile、JetBrains、Xcode、Eclipse 選用；採用量計費。
- Business／Enterprise 由管理員在模型政策管理，預設啟用時新模型自動開啟。
