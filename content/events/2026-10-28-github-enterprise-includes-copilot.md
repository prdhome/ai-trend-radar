## 已確認事實

- GitHub changelog（2026-10-28）：與 GitHub 或 Microsoft 帳號團隊合作的企業，可取得每位 GitHub Enterprise 授權使用者皆內含 Copilot 的方案。
- AI 用量自第一個請求起計入企業預算，沿用既有政策、警示與歸屬；沒有內含用量額度可追蹤或補充。
- 程式碼補全與 next edit suggestions 在預算用盡時仍可使用；Copilot Chat、code review 與雲端 Copilot 需有可用預算。預算用盡不會移除座位。
- 企業帳號內無 GitHub Enterprise 授權的使用者可透過 Copilot Standalone 取得，每人每月 US$10，功能與模型同 Copilot Enterprise，但不含每座位每月 AI credits。
- 帳號團隊客戶即日起適用於 GitHub Enterprise Cloud；自助型客戶目前不可用，將分階段開放，日期「未來數週」公布。現有訂閱不受影響；Copilot Business 與 Enterprise 仍可購買。
