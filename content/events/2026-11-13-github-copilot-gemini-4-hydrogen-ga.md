## 已確認事實

- GitHub Changelog（2026-11-13）：Gemini 4 Hydrogen（Google 的 Flash 級模型）在 GitHub Copilot 正式提供（GA）；官方稱其針對快速、高效的 agent 式編碼、工具使用與多步驟流程，指令遵循優於 Gemini 3.8 Flash。
- 適用方案：Copilot Pro、Pro+、Max、Business、Enterprise；逐步推出，可能不會立即出現。
- 可用用戶端：VS Code、Visual Studio、Copilot CLI、Copilot coding agent、GitHub Copilot app、github.com、GitHub Mobile（iOS／Android）、JetBrains、Xcode、Eclipse、Copilot SDK。
- 頁面未列 premium 倍率；稱在用量計費下以供應商牌價計費，並指向模型與定價文件。
- Business／Enterprise 管理員透過 Copilot 設定中的模型政策管理；預設模型啟用下新模型自動啟用，除非管理員關閉全域預設或明確停用。
- 已讀取該 changelog 頁（經摘要擷取）。

## 對我的影響（推論）

- 以下為推論：預設自動啟用代表企業若不想開放新模型，需主動停用。
