## 已確認事實

- GitHub Changelog（2026-09-29）：OpenAI 的 GPT-6.1 Sol 已在 GitHub Copilot 正式提供，定位為「agentic coding 與終端機工作流」；開放給 Copilot Pro+、Max、Business、Enterprise，逐步 rollout；採 usage-based billing 並以供應商牌價計費。Business／Enterprise 管理員可由模型政策設定，新模型預設啟用。
- 該 GitHub 頁面未連結 OpenAI 官方公告。

## 對我的影響（推論）

- 以下是推論，並非官方說法：若下列報導的價格屬實，且 Copilot 以牌價計費，使用 GPT-6.1 Sol 的實際成本可能低於前代旗艦；需自行實測。

## 仍待確認

- 以下僅來自搜尋結果摘要（TechCrunch 等頁面因網路限制無法讀取，OpenAI 官方頁面亦未讀取），均未驗證：2026-09-29 於 DevDay 發布；API 模型名 `gpt-6.1-sol`，價格 input $2／output $10 每百萬 token、cached input $0.10；號稱接近 GPT-6 Astra 且價格約其五分之一；ChatGPT Work 與 Codex 對 Plus、Pro、Business、Enterprise、Edu 開放；Ultrafast 選項稍後推出。
