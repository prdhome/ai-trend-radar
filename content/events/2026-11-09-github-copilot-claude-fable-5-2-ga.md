## 已確認事實

- GitHub changelog（2026-11-09）：Claude Fable 5.2 在 GitHub Copilot 正式提供（generally available）。
- 適用方案：Copilot Pro+、Max、Business、Enterprise；Business 與 Enterprise 需由管理員啟用 Claude Fable 5.2 政策，預設為關閉。
- 支援的用戶端：Visual Studio Code、Visual Studio、Copilot CLI、Copilot coding agent、GitHub Copilot app、github.com、GitHub Mobile（iOS／Android）、JetBrains、Xcode、Eclipse。
- 逐步推出；尚未看到模型者請稍後再查。
- 頁面說明該模型在使用量計費下以供應商牌價計費，未列出 premium 倍率。
- 頁面稱 Fable 5.2 預設需保留資料供 Anthropic 安全分類器使用；符合資格的企業可在年底前以限時豁免使用零資料保留。
- 已讀取該 changelog 頁全文（經摘要擷取）。

## 對我的影響（推論）
