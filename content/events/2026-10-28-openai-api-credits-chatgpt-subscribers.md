## 已確認事實

- OpenAI developers changelog（2026-10-28）：符合資格的 ChatGPT Pro 與 Business 訂閱者，可領取每月最多 US$500 的免費 API 額度，作為訂閱福利。
- 啟用方式：從 ChatGPT 或 API Platform 連結自己擁有的 API 組織。
- 公告指向「API credits for ChatGPT subscribers」指南說明金額、資格與領取方式；該指南本次未能讀取（嘗試的網址回 404）。
- 已讀取官方 changelog 該條目全文。

- 以下為推論：實際可領額度可能依方案與地區而異，不可直接當作所有訂閱者皆適用。
