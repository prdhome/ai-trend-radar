## 已確認事實

- GitHub Changelog（2026-10-23，標為 Improvement）：原「GitHub notifications」app 整合 Copilot，可在頻道、群組或私訊收到通知後 @GitHub 處理更新。
- 範例流程：Teams 收到 bug 回報，GitHub 調查、修正並建立 PR，團隊再審查、測試、合併。
- 已安裝 GitHub notifications 者需更新 app，既有通知功能持續可用。
- 舊 GitHub app 將改名為「GitHub (deprecated)」並於 11 月 16 日退役；要繼續在 Teams 使用 Copilot 需安裝整合版。
- 設定方式：在整合版 app 中 @GitHub，依指示連結 GitHub 帳號並選擇儲存庫。
- 已讀取該 changelog 條目（經摘要擷取）。

## 對我的影響（推論）

- 以下為推論：公司 Teams 若仍使用舊 app，需由管理員安排遷移；是否需要額外 Copilot 授權由方案決定，頁面未說明。
