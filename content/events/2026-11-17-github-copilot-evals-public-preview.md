## 已確認事實

- GitHub changelog（2026-11-17）：GitHub Copilot Evals 用於測試 Copilot 的 skills、自訂 agent 與 MCP 工具行為；eval 定義為「可重複的 AI 行為測試」。
- 可建立 eval、經核准後執行、檢視失敗檢查，並比較變更前後的執行；引擎為 Vally（本機、可擴充的 eval 工具）。
- 公開預覽，適用 Copilot Individual、Business、Enterprise。
- 安裝：VS Code 安裝 GitHub Copilot Evals 擴充；Copilot CLI 依 github/evals repo 說明安裝外掛；Copilot app 於 Customize 加入 github/evals marketplace。
- 已讀取該 changelog 頁（經摘要擷取）。
