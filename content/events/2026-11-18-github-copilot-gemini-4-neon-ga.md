## 已確認事實

- GitHub changelog（2026-11-18）：Gemini 4 Neon 在 GitHub Copilot 為 generally available，定位為 agentic coding、多步工具使用與知識工作。
- 適用方案：Copilot Pro+、Max、Business、Enterprise；模型選單涵蓋 VS Code、Visual Studio、Copilot CLI、coding agent、Copilot app、github.com、GitHub Mobile、JetBrains、Xcode、Eclipse。採逐步推出。
- Business／Enterprise 管理者透過 Copilot 設定中的模型政策管理；預設模型啟用下，新模型自動啟用，除非管理者已關閉全域預設或明確停用。
- 計費：頁面稱「依使用量計費下，以供應商牌價計費」，未載明倍率。
- 依 Google 說法（廠商宣稱，未獨立驗證）：品質接近 Gemini 4 Carbon、每任務 token 成本較低、回應較快。
- 已讀取該 changelog 頁（經摘要擷取）。

## 對我的影響（推論）

- 以下為推論：若成本是考量，可在實際任務上比較 Neon 與 Carbon；廠商宣稱不等於獨立評測。
